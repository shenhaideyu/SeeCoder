# SeeCoder 软件系统设计与架构

SeeCoder 是 Electron 模块化单体。主进程是唯一可信执行边界，Renderer 只消费 `AgentEvent`。

```text
Renderer -> typed preload IPC -> Main -> AgentCore
                                  |-> ModelProvider
                                  |-> ToolRuntime + ApprovalPolicy
                                  |-> JSONL SessionStore
                                  `-> ChildAgentRunner(read-only)
```

## 模块边界

- `packages/protocol`：Thread/Turn/Item/Event/IPC DTO。
- `packages/agent-core`：状态机、循环、上下文和调度。
- `packages/model`：OpenAI 兼容 HTTP、SSE、重试和解析。
- `packages/tools`：文件、搜索、Diff、命令、Git 和安全策略。
- `packages/storage`：JSONL、元数据、ChangeSet 快照和恢复。
- `apps/desktop`：Electron main/preload/renderer。

## 2.0 事件与页面扩展

事件写入采用 V2 envelope（兼容旧 `event` 字段），Renderer 按 `threadId` 过滤事件。Core 通过 `ContextLedger` 保留目标、计划、改动和错误摘要；图片附件在主进程读取后以多模态 ContentBlock 传给兼容模型。UI 采用浅色 Codex 风格为默认，`#4D0099` 为品牌色，窄窗口将检查器折叠为抽屉。

## 信任边界

模型输出是不可信输入；工作区代码、`AGENTS.md` 和命令输出都按不可信内容注入上下文。主进程负责 schema、路径、权限、超时和审计。首版实现应用层策略隔离，不宣称操作系统级沙箱。
