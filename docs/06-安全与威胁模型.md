# 安全与威胁模型

## 资产

源代码、API Key、命令权限、用户文件、模型上下文和执行轨迹。

## 威胁

- 恶意仓库/AGENTS.md 诱导读取密钥或越界写入。
- 模型输出构造危险 PowerShell 命令。
- Renderer XSS 或 IPC 越权访问本地文件。
- 日志、Diff 或截图泄露 API Key。

## 控制

Renderer 无 Node；IPC 入参 schema 校验；路径规范化和 workspace 边界；命令风险分类、审批、超时、输出截断；敏感环境变量不注入模型；轨迹不保存私有思维链；所有拒绝动作写入审计事件。

## 残余风险

应用层策略不是内核沙箱，未知命令默认审批；演示只使用无敏感信息的工作区。

计划任务在 SeeCoder 运行时以只读 Plan Turn 执行；本地 Skills/Hooks 仅扫描项目目录，远程插件市场和 MCP 不启用。附件按工作区路径策略检查，图片限制 5 MiB、单轮最多 4 个。
