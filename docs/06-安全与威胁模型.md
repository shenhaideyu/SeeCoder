# SeeCoder 安全与威胁模型

## 1. 安全目标

SeeCoder 必须让模型能够完成本地开发任务，同时阻止模型、恶意仓库内容或受损 Renderer 获得不受控的系统权限。

## 2. 资产

- 用户源码和未提交修改。
- API Key 与环境变量。
- 文件写入和命令执行能力。
- 会话、Diff、测试输出和工作区路径。
- Git 分支、暂存区和远端仓库。

## 3. 信任边界

| 区域 | 信任级别 | 原因 |
| --- | --- | --- |
| Electron Main | 可信 | 持有本地权限并执行策略 |
| Agent Core/Tools | 可信代码 | 负责校验模型动作 |
| Renderer | 低信任 | 可能受 UI 注入影响 |
| 模型输出 | 不可信 | 可能生成错误或危险调用 |
| 工作区、AGENTS.md、工具输出 | 不可信数据 | 仓库可包含 Prompt Injection |
| 远程模型服务 | 外部系统 | 会接收明确构造的上下文 |

## 4. 主要威胁与控制

### 4.1 路径穿越和符号链接逃逸

`WorkspacePolicy.path` 先做词法 `relative` 检查，再解析已存在祖先的 realpath。新文件沿最近存在祖先规范化，可阻止通过链接目录写到工作区外。敏感文件名在同一边界拒绝。

### 4.2 凭据泄露

- `.env`、私钥、secret、credential、token、apikey 等路径不遍历、不搜索、不读取。
- `.env.example/.sample/.template` 作为安全模板允许读取。
- Key 可来自 `SEECODER_API_KEY`，或由 Electron `safeStorage` 使用 Windows DPAPI 加密后将密文写入用户配置。
- 明文只进入 Main 进程环境，不通过 IPC 返回。
- 日志只记录 `hasApiKey/keyStorage`，不记录 Key。

### 4.3 危险命令

高风险正则识别删除、格式化、关机、注册表、网络下载、安装依赖和危险 Git 操作。Plan 直接禁止命令；Guided 逐次审批；Auto 也不会自动放行高风险命令。

正则不是完整 Shell 沙箱，复杂别名或编码仍可能绕过，因此未知命令不能被描述为安全。当前主要控制仍是最小工具面、工作区 cwd、审批与审计。

### 4.4 Renderer 越权

Renderer 无 Node 集成，通过固定 preload 方法调用 Main。IPC 再做长度、枚举、路径和 schema 校验。当前 Chromium `sandbox` 为 false 是残余风险，不能用 `contextIsolation` 替代 OS 沙箱声明。

### 4.5 Prompt Injection

系统提示明确声明工作区内容和 `AGENTS.md` 是不可信数据，不能覆盖安全规则。真正的防线仍在 Core：即使模型被诱导，Plan、Zod、WorkspacePolicy、审批和工具白名单仍执行。

### 4.6 数据覆盖

单文件使用临时文件加 rename 原子替换；ChangeSet 保存 before/after；Checkpoint 恢复前验证 afterHash。用户修改过文件后拒绝恢复。

## 5. 命令进程安全

- PowerShell 使用 `-NoProfile -NonInteractive`。
- cwd 必须经过 WorkspacePolicy。
- 默认超时 60 秒，schema 最大 120 秒。
- 输出按 stdout/stderr 分流，每路保留约 1 MiB。
- 取消和超时在 Windows 使用 `taskkill /pid /t /f` 终止进程树。

## 6. 数据保留

会话位于 `%APPDATA%/SeeCoder`，不是仓库。JSONL 保存用户可见消息、工具参数、结构化结果和验证证据，不保存私有思维链。导出功能可能包含用户代码和路径，因此由用户主动选择保存位置。

## 7. 残余风险

- 没有 OS 级文件、网络和进程沙箱。
- `sandbox: false` 降低了 Renderer 受攻陷后的防御深度。
- 命令风险分类是规则识别，不是 PowerShell AST 安全分析。
- 多文件补丁虽先验证所有内容，但最终逐文件写入，极端 I/O 故障可能部分完成。
- JSONL 和快照未额外加密，依赖用户账户与操作系统文件权限。
- 模型服务会看到被选入上下文的代码。

## 8. 不应作出的安全声明

- 不声称“命令绝对安全”。
- 不声称“模型无法访问网络”；命令若经用户批准仍可能联网。
- 不声称“数据端到端加密”；模型请求发送给配置的服务商。
- 不声称“等同 Codex 操作系统沙箱”。
