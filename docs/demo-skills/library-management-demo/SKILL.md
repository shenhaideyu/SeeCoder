# 图书馆管理系统演示

## 目标

创建一个结构清楚、操作完整、方便现场演示的图书馆管理系统。优先保证核心流程可运行，不扩展与演示无关的复杂功能。

## 默认范围

当用户没有指定技术和产品细节时：

- 空工作区使用 React、TypeScript 和 Vite；已有项目沿用原技术栈。
- 使用本地状态和 localStorage 保存数据，不额外创建后端、数据库或登录系统。
- 图书包含编号、书名、作者、ISBN 和借阅状态。
- 支持列表、搜索、新增、编辑、删除、借阅和归还。
- 界面使用中文，保持布局简洁，并适配常见桌面宽度。

用户提出不同要求时，以用户要求为准。

## 工作方式

1. 先检查当前工作区，确认是空项目还是已有项目。
2. 在 Plan 模式下，只输出页面结构、数据模型和实施步骤，不修改文件。
3. 进入 Guided 或 Auto 模式后，按照已确认的计划实现，不重新扩大需求。
4. 优先完成可见页面和核心操作，再补充输入校验、空状态和错误提示。
5. 完成后运行项目已有的类型检查、测试或构建命令，并说明验证结果。

## 设计要求

- 首页直接展示图书列表、搜索框和新增入口。
- 新增与编辑复用同一套表单。
- 已借出的图书不能重复借阅；归还后恢复为可借状态。
- 删除和借阅等重要操作要有明确反馈。
- 保持组件职责简单，避免为演示项目引入复杂状态框架。

## 完成标准

- 应用能够正常启动。
- 七项核心操作均可在界面中完成。
- 页面没有明显布局溢出。
- 最终回答简要列出已实现功能、关键文件和验证结果。
