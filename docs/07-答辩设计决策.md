# 答辩设计决策

1. 不用 Agent SDK：考核要求核心逻辑自研，直接 HTTP/SSE 还能清晰展示解析、调度和终止。
2. 用 Electron：本地文件、子进程和高保真三栏 UI 在同一桌面应用内闭环，Renderer 仍保持隔离。
3. 主 Agent 单写者：避免多个模型同时修改同一文件，子 Agent 通过只读证据提高可靠性。
4. JSONL 而非数据库：追加式轨迹天然可审计、可恢复，Demo 规模无需数据库迁移。
5. Guided/Auto 两档：让低风险循环顺滑，同时对未知命令、网络和删除保留人工判断。
6. 事件驱动：UI 不读取 Core 内部对象，只订阅稳定事件，未来可替换 CLI 或其他客户端。
