## 实现地图

| 领域 | 代码入口 | 主要职责 |
| --- | --- | --- |
| 公共协议 | `packages/protocol/src/index.ts` | Thread、Turn、Item、事件、模型消息和工具结果 |
| Agent Harness | `packages/agent-core/src/index.ts` | 循环、上下文、审批、终止、子 Agent 和恢复 |
| 模型接入 | `packages/model/src/index.ts` | Chat Completions、SSE、tool-call 增量与重试 |
| 本地工具 | `packages/tools/src/index.ts` | 路径策略、文件、补丁、命令和 Git Diff |
| 会话存储 | `packages/storage/src/index.ts` | V2 JSONL、元数据、账本和快照 |
| 可信后端 | `apps/desktop/src/main/main.ts` | Electron 生命周期、IPC、密钥、工作区和计划任务 |
| 权限桥 | `apps/desktop/src/preload/preload.ts` | 最小化、类型化 Renderer API |
| 用户界面 | `apps/desktop/src/renderer/main.tsx` | 对话、审批、Changes、Files、Terminal 和 Trace |

## 架构原则

1. **模型不可信。** 模型只能提出工具调用，不能直接获得 Node.js、文件系统或进程权限。
2. **主 Agent 单写者。** 子 Agent 只读，避免并行修改冲突和责任不清。
3. **事件是 UI 的事实来源。** Renderer 不读取 Agent Core 内部对象。
4. **状态必须可终结。** 完成、失败、取消、中断和达到上限都必须成为明确终态。
5. **完整轨迹与模型上下文分离。** 审计记录可以完整保留，发送给模型的上下文必须裁剪。
6. **安全声明不超出实现。** 当前是应用层策略隔离，不是操作系统级沙箱。

## 文档中的状态

- “已实现”：当前源码和测试中存在对应行为。
- “设计限制”：有意缩小的首版范围。
- “残余风险”：当前机制不能完全消除的问题。

## 事实优先

若文档与源码出现冲突，以已测试源码为准，并应立即修正文档。尤其需要注意：

- `BrowserWindow` 使用 `contextIsolation: true`、`nodeIntegration: false`，但当前为兼容 ESM preload 设置了 `sandbox: false`。
- API Key 可以来自环境变量，也可以由 Electron `safeStorage` 加密后持久化；明文不写入设置、日志和仓库。
- 上下文压缩是确定性摘要与最近消息保留，不是另一次模型摘要调用。
- `apply_patch` 会先验证所有补丁内容，但多文件最终写入仍是逐文件原子替换，不具备跨文件事务。
